# DecodeLabs Project 2 - EC2 Website Hosting

## Technologies Used
- AWS EC2
- Amazon Linux 2023
- Apache Web Server
- HTML
- CSS

## Steps Performed
1. Created EC2 instance.
2. Connected using PowerShell.
3. Installed Apache.
4. Copied website files to /var/www/html/.
5. Started Apache service.
6. Accessed website using EC2 Public IP.

## Output
Website successfully hosted on AWS EC2.
